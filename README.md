# Toolsmith (fork)

This is a personal fork of [Mario90900/Toolsmith](https://github.com/Mario90900/Toolsmith) used to stage pull request contributions back upstream. It is not a separate mod release.

For the actual mod, including installation, documentation, releases, and bug reports, please use the upstream repo or the [ModDB modpage](https://mods.vintagestory.at/show/mod/22096).

If you've landed here looking for a specific PR, check the [Pull Requests](https://github.com/Mario90900/Toolsmith/pulls?q=author%3ATirello-Nardell) page on the upstream repo.
